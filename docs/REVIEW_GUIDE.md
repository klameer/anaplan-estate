# Independent review exercise

This is a way to collect feedback, not a claim that independent review has
already taken place. The full protocol is in [VALIDATION.md](../VALIDATION.md).

## A first review on fictional data

Use the bundled Caldergate estate. Without assistance from the author:

1. Choose one suggested action and explain why you would investigate it.
2. Identify its evidence, one uncertainty, and a reason to leave the design unchanged.
3. Select a line item and trace one downstream dependency through the explorer.
4. Describe the check you would require before approving the proposed change.

Record the elapsed time, any navigation problem, unsupported conclusion or
missing context. Compare the result with the planted-scenario notes only
after the first pass. Success on this fixture tests usability and known
mechanics, not usefulness on an unfamiliar real estate.

## An unfamiliar estate

Run locally with the owner's permission. Before opening the report, record
the expected issues and worthwhile actions. Freeze the first report before
tuning the rules. Compare correct findings, false alarms, missed issues,
useful recommendations and unsupported advice separately. Keep one estate
outside all tuning if practical.

Do not post private exports, formula names or confidential details in a
public issue. A fictional minimal example is enough to report a defect.

measured operational benefits only after a validated change and comparable
before/after readings; agreement with a suggestion is not a saving.
